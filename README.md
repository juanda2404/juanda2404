## 🚀 Proyectos Destacados

### 🛒 [Customer Churn Analytics](./big-data-churn-analytics)
Pipeline ETL distribuido para procesar datos de comportamiento de usuarios e identificar patrones de fuga de clientes.
*   **Tecnologías**: PySpark, Apache Cassandra, Docker, Python.
*   **Destacado**: Orquestación multinodo con contenedores, procesamiento paralelo de variables e integración analítica con NoSQL.

### 📦 [Delivery & Logistics System (Oracle SQL)](./delivery-logistics-oracle-sql)
Diseño conceptual, lógico y físico de una base de datos relacional para un servicio logístico de reparto urbano.
*   **Tecnologías**: Oracle SQL, SQL Developer, Modelado E-R.
*   **Destacado**: Scripts DDL/DML, implementación de triggers, normalización y aplicación de reglas de cardinalidad complejas.

### 🚗 [Highway Traffic Simulator](./highway-traffic-simulator-c)
Módulos desarrollados en lenguaje C enfocados en rendimiento algorítmico, simulación concurrente y gestión de memoria.
*   **Tecnologías**: C, Gestión de Memoria Dinámica.
*   **Destacado**: Estructuras de datos personalizadas (listas, árboles, hash) y gestión rigurosa de punteros sin *memory leaks*.
